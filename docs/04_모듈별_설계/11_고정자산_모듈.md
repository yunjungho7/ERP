# 11. 고정자산 모듈 설계 계획서

> 목적: 취득→감가상각→처분까지 자산 라이프사이클과 상각 자동분개 — 자산대장의 장부 정합성 유지.
> 우선순위: P2. 공통 프레임워크는 [00_공통_설계기반.md](00_공통_설계기반.md) 참조.

---

## 1. 범위

- 포함: 자산 등록(취득), 월별 감가상각(정액/정률), 이동(부서·사용자 변경), 처분, 자산대장·상각명세
- 제외: 무형자산·개발비 세분류, 재평가·손상차손, 물적 자산 태그/실사 — P2 후순위~제외

## 2. 화면/메뉴

| 메뉴 | 기능 |
|---|---|
| 자산 등록 | 취득일·취득가·내용연수·상각방법·부서·관리자 |
| 감가상각 실행 | 월 단위 일괄 상각 계산·확정 → 분개 |
| 자산 이동·변경 | 부서/사용자/내용연수 변경 이력 |
| 자산 처분 | 매각·폐기 — 상각누계 정산, 처분손익 |
| 자산대장·상각명세 | 자산별 취득가·상각누계·장부가 |

## 3. 데이터 모델

| 테이블 | 주요 컬럼 |
|---|---|
| `fixed_asset` | asset_no, name, acq_date, acq_cost, useful_life, method(straight/declining), residual?, dept_id, manager_id, status(active→disposed) |
| `depreciation_run` + `_line` | year_month, status(calc→posted) / asset_id, amount, accum_after, book_value_after |
| `asset_disposal` | asset_id, dispose_date, type(매각/폐기), proceeds, gain_loss — posted 시 분개 |

## 4. 처리 규칙

- 월 상각: 정액 = (취득가−잔존가)/내용연수/12, 정률 = 장부가×율/12 — 취득·처분월 일할은 설정(월할 기본).
- 상각 런은 월 1회 — `posted` 시 자산별 분개 합산 → 회계 자동분개. 중복 실행은 멱등키 차단.
- 처분: 상각누계 정산 후 장부가와 처분가의 차 = 처분손익으로 분개.
- 분개: 취득 `유형자산/외상매입금(or 보통예금)`, 상각 `감가상각비/감가상각누계액`, 처분 `보통예금+감가상각누계액/유형자산+처분손익`.

## 5. API 스케치

```
/assets                   GET/POST/PATCH, :move
/assets/depreciation/runs GET/POST, :calc :post
/assets/disposals         GET/POST, :post
/assets/ledger            GET (자산대장)
```

## 6. 연동·이벤트

- 발행: `depreciation_run.posted`, `asset_disposal.posted` → 회계 자동분개
- 취득은 수기 등록(P2) — 매입 연동 자동 자산화는 후순위.

## 7. 수용 기준

- [ ] 정액/정률 상각 계산 정확, 월 상각 런 중복 불가
- [ ] 상각·처분 posted 시 정확한 분개 생성
- [ ] 자산대장 장부가 = 취득가−상각누계 일치

## 8. 후순위·미결

- 매입→자산 자동 등록, 무형자산, 재평가·손상, 자산 실사·태그 — 후순위~제외
