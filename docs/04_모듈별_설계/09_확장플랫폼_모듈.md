# 09. 확장플랫폼 모듈 설계 계획서

> 목적: 상용화의 생명줄 — 고객이 코드 포크 없이 쓰는 커스터마이징 수단(커스텀 필드·인쇄 양식·승인/채번 규칙·API/웹훅). Clean Core 원칙의 구현체.
> 우선순위: P1부터 점진 도입. 공통 프레임워크는 [00_공통_설계기반.md](00_공통_설계기반.md) 참조.

---

## 1. 범위

- 포함: 테넌트별 커스텀 필드, 인쇄 양식 템플릿, 승인 규칙, 채번 규칙, 테넌트별 API 키·웹훅, 기능 플래그
- 제외: 화면 자유 편집(폼 빌더), 스크립트/워크플로 엔진, 마켓플레이스 앱 — P2~제외

## 2. 화면/메뉴

| 메뉴 | 기능 |
|---|---|
| 커스텀 필드 | 엔티티별 추가 필드 정의(유형·필수·기본값·선택지) |
| 인쇄 양식 | 문서별 출력 템플릿 편집·미리보기·버전 |
| 승인 규칙 | 문서 종류별 승인 단계·승인자 설정 |
| 채번 규칙 | 문서 번호 패턴(접두·연도·자릿수) 설정 |
| API·웹훅 | 테넌트 API 키 발급, 이벤트 구독 URL·필터·전달 로그 |
| 기능 플래그 | 테넌트별 모듈·기능 On/Off |

## 3. 데이터 모델

| 테이블 | 주요 컬럼 |
|---|---|
| `custom_field_def` | entity, field_key, type(text/number/date/select/ref), required, options, order, is_active |
| `print_template` | doc_type, name, html(→PDF), version, is_default |
| `approval_rule` + `_line` | doc_type, condition? / seq, approver(role/user), required |
| `sequence_rule` | doc_type, pattern(`{모듈}-{유형}-{YYYY}-{seq:06d}` 변형), reset_period |
| `api_key` | tenant, key_hash, scope, is_active |
| `webhook_subscription` + `_delivery` | event_pattern, url, secret / event_id, status, attempts, response |
| `tenant_feature_flag` | feature_key, enabled |

## 4. 처리 규칙

- 커스텀 필드 값은 문서 행의 `custom_fields` JSONB — 저장 시 def 기준 타입·필수 검증, 폼·그리드·API 응답에 자동 반영.
- 인쇄: 문서 `:print` → is_default 템플릿 렌더 → PDF. 템플릿 문법은 단순 치환(필드+반복 라인)부터 시작, 스크립트 금지.
- 승인: `draft → 승인대기 → 승인 → confirmed` — 규칙 없으면 기존 상태머신 그대로(승인 단계 생략).
- 웹훅: outbox 이벤트를 구독 패턴에 매칭 → 서명(HMAC) POST → 실패 시 지수 백오프 재시도, delivery 로그 보존.

## 5. API 스케치

```
/platform/custom-fields      GET/POST/PATCH ?entity=
/platform/print-templates    GET/POST/PATCH, 문서별 POST :print → PDF
/platform/approval-rules     GET/POST/PATCH, 문서별 :approve :reject
/platform/sequence-rules     GET/POST/PATCH
/platform/api-keys           POST(발급)/DELETE(폐기)
/platform/webhooks           GET/POST/PATCH/DELETE, GET /{id}/deliveries
/platform/feature-flags      GET/PATCH
```

## 6. 수용 기준

- [ ] 커스텀 필드 추가가 폼·그리드·API에 코드 변경 없이 반영
- [ ] 인쇄 템플릿 변경이 출력 PDF에 즉시 반영
- [ ] 승인 규칙 설정 시 문서가 승인 단계를 거침
- [ ] 웹훅이 이벤트 발생 시 서명 포함 전달, 실패 재시도 로그 확인

## 7. 후순위·미결

- 폼 빌더·조회 조건 커스터마이징, 스크립트 훅, 앱 마켓플레이스 — P2~제외
- 미결: 커스텀 필드 타입 범위(참조형 ref를 P1에 넣을지) — text/number/date/select부터 시작 권장.
