# 10. 인사급여 모듈 설계 계획서

> 목적: 인사 기록 + 급여 계산·신고 자료 — 매년 바뀌는 요율·세액표를 코드가 아니라 기준 데이터로 관리하는 것이 설계 핵심.
> 우선순위: P2. 공통 프레임워크는 [00_공통_설계기반.md](00_공통_설계기반.md) 참조.

---

## 1. 범위

- 포함: 인사카드·발령, 근태 연동(그룹웨어 소유), 급여 계산(기본급·수당·공제·상여), 퇴직정산, 원천세·4대보험 신고 자료, 연말정산 기초
- 제외: 연말정산 간소화 자동 연동, 전자근로계약·전자서명, 성과·평가 — P2 후순위~제외

## 2. 화면/메뉴

| 메뉴 | 기능 |
|---|---|
| 인사카드 | 입퇴사·계좌·부양가족·자격 — 고유식별정보 암호화 |
| 발령·인사기록 | 부서·직급 변경 이력, 증명서 발급 |
| 근태 조회 | 그룹웨어 연동 근태 데이터 조회·급여 반영용 확정 |
| 급여 계산 | 월 급여 실행(대상자 일괄), 명세서, 상여·특별 지급 |
| 퇴직정산 | 퇴직금 산정·지급 내역 |
| 원천세·4대보험 자료 | 신고서식 합계표·파일 |
| 연말정산 | 소득·세액 집계, 정산 결과 급여 반영 |
| 연도별 기준데이터 | 간이세액표·4대보험 요율·공제 기준 관리 |

## 3. 데이터 모델

| 테이블 | 주요 컬럼 |
|---|---|
| `hr_employee_ext` | employee_id, 입퇴사일, 계좌(암호화), 주민번호(암호화), 부양가족 JSON, 고용형태 |
| `appointment` | employee_id, type(입사/발령/승진/퇴사), effective_date, from/to dept·grade |
| `pay_item` | 지급/공제 항목 정의 — code, name, type(수당/공제), calc_expr, taxable |
| `payroll_run` + `_line` | year_month, status(calc→confirmed→posted) / employee_id, item별 금액, 지급합계·공제합계·실수령 |
| `annual_policy` | year, key(간이세액표/국민연금/건강보험/고용보험/산재/최저임금), value JSON — **매년 기준 데이터로 갱신** |
| `severance_calc` | employee_id, 퇴사일, 평균임금 산정, 퇴직금 |
| `attendance_ref` | 근태 확정치 참조(그룹웨어 연동 키) — 소유권은 그룹웨어 |

## 4. 처리 규칙

- 요율·간이세액표·공제한도는 전부 `annual_policy` 조회 — 코드/배포 없이 연도 갱신.
- 급여 계산 = pay_item calc_expr 적용(사람별 고정값 + 규칙식), 결과는 `_line`에 확정 스냅샷으로 저장(재계산 추적 가능).
- `payroll_run.posted` → 회계 자동분개(급여/미지급금/예수금 등). 분개 규칙은 posting_rule로 관리.
- 고유식별정보(주민번호·계좌)는 암호화 저장 + 접근 권한 분리 + 조회 감사로그.

## 5. API 스케치

```
/hr/employees           GET/POST/PATCH (hr_employee_ext)
/hr/appointments        GET/POST
/hr/pay-items           GET/POST/PATCH
/hr/payroll/runs        GET/POST, :calc :confirm :post
/hr/severance           GET/POST, :calc
/hr/annual-policies     GET/POST/PATCH ?year=
/hr/reports/withholding GET ?year=&month=  (원천세 자료)
```

## 6. 연동·이벤트

- 구독: 근태 확정(그룹웨어 API 주기 수집 또는 이벤트)
- 발행: `payroll_run.posted` → 회계 분개, `payroll_run.confirmed` → 명세서 알림

## 7. 수용 기준

- [ ] annual_policy 기준으로 급여 계산 결과 정확(샘플 급여 검증)
- [ ] 급여 posted → 정확한 급여 분개 생성
- [ ] 주민번호·계좌 암호화 저장, 권한자 외 조회 차단·감사 기록
- [ ] 원천세 신고 자료 합계 = 급여 합계와 일치

## 8. 후순위·미결

- 연말정산 간소화 API, 전자근로계약, 성과평가·승진심사 — P2 후순위~제외
- 미결: 근태 데이터 소스 — 그룹웨어 연동(권장) vs ERP 자체 근태 입력 병행 여부.
