# 13. 원가 모듈 설계 계획서

> 목적: 실적 원가 집계·품목별 원가·재공품 평가 — 생산 수불(08)과 회계 원장(05)을 잇는 원가 계층. 제조업 타깃 상용화의 필수 후속.
> 우선순위: P2. 공통 프레임워크는 [00_공통_설계기반.md](00_공통_설계기반.md) 참조.

---

## 1. 범위

- 포함: 원가 요소(재료비·노무비·경비), 배부 기준, 월 원가 마감 실행, 품목별·지시별 원가, 재공품 평가
- 제외: 표준원가·활동기준원가(ABC)·원가 시뮬레이션·판가 분석 — P2 후순위~제외

## 2. 화면/메뉴

| 메뉴 | 기능 |
|---|---|
| 원가 요소·배부 기준 | 비용 항목 정의, 배부 기준(수량·금액·작업시간) 설정 |
| 원가 마감 | 월 단위 원가 집계·배부 실행, 결과 검토 후 확정 |
| 품목별 원가 | 기간별 품목 원가(재료비/노무비/경비 구성) |
| 지시별 원가 | 작업지시별 투입·산출 원가 비교 |
| 재공품 평가 | 월말 재공품 수량×진척도 평가 |

## 3. 데이터 모델

| 테이블 | 주요 컬럼 |
|---|---|
| `cost_element` | code, name, type(material/labor/overhead), source(재고불출/급여분개/경비전표) |
| `cost_alloc_rule` | element_id, basis(qty/amount/work_hours), target(item/work_order) |
| `cost_run` + `_line` | year_month, status(calc→confirmed→posted) / item_id, material, labor, overhead, total, unit_cost |
| `wip_valuation` | run_id, work_order_id, qty, progress_rate, amount |

## 4. 처리 규칙

- 월 원가 마감: 기간의 `material_issue`(재료비) + `payroll` 노무비 배정 + 경비 분개를 배부 기준으로 품목·지시에 배부 → `cost_run` 확정.
- 확정 원가로 `production_receipt` 입고 단가 보정 → `stock_ledger` 재평가(원가조정) 가능하도록 훅.
- 재공품: 월말 미완료 지시의 투입비×진척도로 평가 → 재공품 자산 분개.
- 원가는 읽기+집계 계층 — 불출·입고 등 수불 자체는 04/08의 규칙 그대로.

## 5. API 스케치

```
/cost/elements          GET/POST/PATCH
/cost/alloc-rules       GET/POST/PATCH
/cost/runs              GET/POST, :calc :confirm :post
/cost/item-costs        GET ?period=&item=
/cost/work-order-costs  GET ?period=
/cost/wip               GET ?period=
```

## 6. 연동·이벤트

- 구독: `material_issue.confirmed`, `production_receipt.confirmed`(08), `payroll_run.posted`(10), `journal_entry.posted`(05) → 배부 입력 수집
- 발행: `cost_run.posted` → 재고 재평가·재공품 분개 이벤트

## 7. 수용 기준

- [ ] 월 원가 마감이 재료비·노무비·경비를 배부 기준대로 품목에 배부
- [ ] 품목별 원가 구성(3요소) 합계 = 기간 투입 총액과 대사
- [ ] 확정 원가가 입고 단가 보정으로 재고 평가에 반영

## 8. 후순위·미결

- 표준원가·ABC·부문별 원가·판가 분석 — 후순위~제외
- 미결: 배부 기준의 초기 범위 — 수량/금액만 P2에 넣고 작업시간은 후순위로 미룰지.
