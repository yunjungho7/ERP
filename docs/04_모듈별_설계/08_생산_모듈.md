# 08. 생산 모듈 설계 계획서

> 목적: 제조업 대상 생산 수불 — 작업지시·자재불출·제품입고·소요량 산출(기초 MRP). 공정·실적은 MES 경계, ERP는 수불·원가·발주제안까지.
> 우선순위: P1 (제조업 타깃 시). 공통 프레임워크는 [00_공통_설계기반.md](00_공통_설계기반.md) 참조.

---

## 1. 범위

- 포함: 작업지시(수주 연결), BOM 전개→자재소요량, 자재불출·제품입고, 발주제안, 생산현황
- 제외: 공정 라우팅·실적수집·불량·설비·공구 → MES(PFMES) 소유, API/이벤트 연동. 외주·정밀 MRP(안전재고·리드타임)·원가배부 — P2.

## 2. 화면/메뉴

| 메뉴 | 기능 |
|---|---|
| 작업지시 | 지시 등록(품목·수량·예정일·수주 연결), 진행 상태 조회 |
| 소요량 산출 | 지시/수주 기준 BOM 전개 → 자재 소요·부족량 계산 (MRP 실행) |
| 자재불출 | 지시별 자재 출고 (재고 연동) |
| 제품입고 | 지시별 완제품/반제품 입고 |
| 발주제안 | 부족 자재 → 구매 발주 제안 리스트 |
| 생산현황 | 지시별 투입·산출·진행률 |

## 3. 데이터 모델

| 테이블 | 주요 컬럼 |
|---|---|
| `bom` + `bom_line` | 기준정보 모듈 소유 — parent_item, version, 유효기간 / child_item, qty, loss_rate |
| `work_order` | doc_no, item_id, qty, planned_start/end, source(수주 연결: sales_order_id), status(draft→confirmed→in_progress→completed→closed) |
| `material_issue` + `_line` | work_order_id / item, qty — confirmed 시 재고 출고 |
| `production_receipt` + `_line` | work_order_id / item, qty, unit_cost — confirmed 시 재고 입고 |
| `mrp_run` + `_result` | 실행일, 기준(work_order/sales_order 범위) / item, required_qty, onhand, shortage → 발주제안 |

## 4. 처리 규칙

- BOM 전개: 재귀 전개(순환 참조 검사 필수), 유효 version만 적용.
- 소요량 = 지시수량 × BOM 소요량 × (1 + loss_rate) — 부족량 = 소요량 − 가용재고.
- 불출·입고는 재고 모듈과 동일 규칙(`stock_ledger` reason=production).
- 분개: 불출 `재공품/원재료`, 입고 `제품/재공품` (간이 원가 — 배부 없이 재료비+기본 단가, 정밀 원가는 P2).

## 5. API 스케치

```
/production/work-orders        GET/POST, :confirm :start :complete :close
/production/material-issues    GET/POST, :confirm :post :cancel
/production/receipts           GET/POST, :confirm :post :cancel
/production/mrp/runs           POST (소요량 산출 실행), GET /{id}/results
/production/order-suggestions  GET (부족 자재 → 발주 제안)
```

## 6. 연동·이벤트

- 구독: `sales_order.confirmed` → 생산 필요 품목 지시 후보
- 발행: `material_issue.confirmed`/`production_receipt.confirmed` → 재고 입출고, `mrp.shortage` → 구매 발주제안, `work_order.completed` → 알림

## 7. 수용 기준

- [ ] 작업지시 → BOM 전개로 소요량·부족량 정확 산출 (순환 BOM 차단)
- [ ] 자재불출·제품입고가 재고 수불에 정확 반영
- [ ] 부족 자재가 발주제안으로 구매 모듈에 연결
- [ ] MES와의 경계: 공정 데이터 없이 수불 단위로 완결 동작

## 8. 후순위·미결

- 외주 가공(외주창고·외주비 정산), 정밀 MRP(리드타임·안전재고·LOT), 정밀 제조원가(노무비·경비 배부), 공정 라우팅 — P2~제외
- 미결: 생산입고 단가 — 재료비 합산 단순법(P1) vs 배부 포함(P2).
